## 1. Why This Brand, Right Now

### 1.1 The strategic moment

ANI Pharmaceuticals (NASDAQ: ANIP) is mid-pivot. A diversified U.S.-based generics manufacturer is becoming a leading rare-disease company:

- 2026 projected revenue: **$1.055–$1.115 billion**
- Rare disease share of revenue (2026): **~60%**
- Cortrophin Gel franchise (2026): **$540–$575M**
- Three FDA-inspected U.S. manufacturing facilities (Baudette MN, East Windsor NJ, Oakville ON)
- A 90-person commercial team for acute gouty arthritis flares deploying mid-2026

The brand needs to do three jobs at once:
1. **Signal modernity** to investors, HCPs, and recruits — "this is the rare-disease company writing the next chapter, not your father's generics maker."
2. **Honor heritage** — manufacturing pride, U.S.-based operations, two decades of compounding quality.
3. **Center patients** — the 'why' of everything that follows.

### 1.2 Brand promise

> **"Care, codified."**

Five letters. Both halves earn each other.
- **Care** — patients at the center of everything.
- **Codified** — encoded with precision: sourced numbers, structured manufacturing, designed systems.

ANI is one of very few rare-disease companies that builds, manufactures, AND commercializes its own medicines. That earns the "codified."

### 1.3 Brand essence

> **Quiet conviction. Patient warmth. Manufactured pride.**

ANI is not a flashy biotech. Not a sleepy generics maker. A builder — compounding quality over time, showing up for the patients others forget.

### 1.4 Brand pillars

Four pillars the entire system serves:

| Pillar | What it means | How it shows up |
|---|---|---|
| **Encoded** | Every claim sourced. Every number cites its data. | Tabular numerics, citation conventions, ISI integrity |
| **Embodied** | We make our medicines with our hands, on American soil. | Manufacturing photography, location-as-thread |
| **Earned** | We don't claim — we demonstrate. | Numbers over adjectives, evidence over enthusiasm |
| **Extended** | A system, not a campaign. Built to last 10 years. | Two-tier tokens, governance, atomic component model |

### 1.5 Brand archetypes (mixed)

- **The Caregiver** (40%) — patient warmth, trust, support
- **The Sage** (40%) — scientific authority, evidence, clarity
- **The Maker** (20%) — manufacturing pride, hands-on craft

### 1.6 What this brand is NOT

- ❌ Generic blue-corporate-pharma
- ❌ Faceless big-pharma
- ❌ Stock-photo-laden brochure
- ❌ Mallinckrodt-Acthar institutional beige
- ❌ Biotech-startup self-important
- ❌ ESG-greenwashed virtue-signal

## 2. Identity & Logo

### 2.1 The mark concept: "Direction"

A horizontal line resolving into a circle at its right end. Reads simultaneously as:

- **A vector** — the direction toward the patient
- **An injection trajectory** — clinical precision
- **A medical chart baseline finding its anchor**
- **A meridian** — a navigational measurement
- **The brand promise made visual** — care leading to its destination

It's a single elegant glyph that scales from favicon to billboard. It's distinctly different from every concentric-circle, double-helix, or capsule logo in the pharma category.

### 2.2 The wordmark

**ANI** is set in Inter Tight (weight 600). Below "ANI" — separated by a thin rule — sits "PHARMACEUTICALS" in Inter (weight 600, all caps, letter-spacing 0.18em, sized at ~28% of the cap height of "ANI").

### 2.3 Lockup variants

| Variant | When to use |
|---|---|
| **Horizontal Primary** (mark + wordmark + tagline) | Default at every standard touchpoint — web header, business cards, signage |
| **Stacked Primary** (mark above wordmark) | Mobile, social avatars, narrow vertical contexts |
| **Wordmark only** | Restricted contexts where the mark would be too small |
| **Mark only** | Below 120px wide — favicon, app icon, social profile pic |
| **Two-tone** (Indigo line + Saffron circle) | Default treatment everywhere |
| **Reverse** (Bone line + Saffron circle) | On dark surfaces (Indigo, Charcoal, photography) |
| **Mono** (single-color) | Faxed, low-fi print, single-color reproduction |

### 2.4 Clear space

Minimum clear space = **2× the cap height of "A" in ANI**, applied on all four sides. No content, photography, or graphic elements may enter this zone.

### 2.5 Minimum sizes

- Horizontal lockup: minimum width **140px** (digital) / **40mm** (print)
- Stacked lockup: minimum width **100px** / **30mm**
- Mark only: minimum **24×24px** / **8mm**

### 2.6 Logo do's and don'ts

| ✓ Do | ✕ Don't |
|---|---|
| Use the two-tone primary lockup as the default | Swap line and circle colors (Saffron line + Indigo circle is wrong) |
| Maintain Indigo line + Saffron circle relationship | Rotate, skew, or distort |
| Use Bone-on-Indigo for dark surfaces | Add drop shadows, glows, or strokes |
| Maintain 2× cap-height clear space | Recolor the wordmark in accent colors |
| Use mark-only at sizes below 120px | Place the mark on busy photography without overlay |
| Lock to approved brand colors only | Stretch the wordmark to fit a container |
| Use the official files from the DAM | Re-typeset "ANI" — always use locked artwork |

## 3. Color System

### 3.1 The three roles

The Meridian palette is built around three roles. Each color serves a distinct purpose. Together they tell the whole brand story.

| Color | Hex | Role |
|---|---|---|
| **Indigo** | `#312E81` | **Brand authority** — corporate, scientific, HCP, investor |
| **Saffron** | `#F59E0B` | **Patient warmth** — attention, optimism, human moments |
| **Teal** | `#0D9488` | **Clinical credibility** — manufacturing, science, data |

Why these three:
- **Indigo** is the most distinctive blue in the pharma category. Pfizer, Merck, BMS, and Mallinckrodt all use corporate navies. ANI gets to own indigo.
- **Saffron** is the smartest yellow — warm, earthy, premium, and energetic. Avoids the youthfulness of lemon and the staid feeling of mustard.
- **Teal** is THE medical credibility color — hospitals, scientific instruments, clinical software. Gives the system a third color that strengthens credibility instead of decorating it.

### 3.6 Contrast verification (WCAG 2.2 AA)

Every brand combination has been measured. Use these confidently:

| Foreground | Background | Ratio | Verdict |
|---|---|---|---|
| `--charcoal-800` on `--bone-200` | | **15.6:1** | ✓ AAA |
| `--indigo-500` on `--bone-200` | | **11.5:1** | ✓ AAA |
| `--saffron-700` on `--bone-200` | | **6.8:1** | ✓ AA Body |
| `--teal-700` on `--bone-200` | | **7.5:1** | ✓ AAA |
| `--bone-100` on `--indigo-500` | | **12.0:1** | ✓ AAA |
| `--charcoal-800` on `--saffron-500` | | **7.2:1** | ✓ AAA — use dark text on Saffron |
| `--bone-100` on `--teal-500` | | **4.6:1** | ✓ AA |
| `--saffron-500` on `--bone-200` | | **3.0:1** | Decorative / large text only |
| `--teal-500` on `--bone-200` | | **4.2:1** | ✓ AA Large only |

**Critical rules:**
- ❌ Never use `--saffron-500` for body text on light surfaces (fails AA)
- ✅ Use `--saffron-700` for body emphasis on light surfaces
- ✅ Saffron CTAs use Charcoal text (not white) — Charcoal-on-Saffron is AAA
- ✅ Indigo CTAs use Bone-100 text — passes AAA
- ✅ Teal-500 works for white text only; use Teal-700 for text on light

### 3.7 Color anti-patterns

- ❌ Don't reference primitive tokens in components — use semantic tokens
- ❌ Don't use `--saffron-500` and `--saffron-700` adjacent — pick one
- ❌ Don't use all three accent colors on a single page (use two max in any one viewport)
- ❌ Don't use color as the only signal for state — always include text or icon
- ❌ Don't introduce a fourth accent — three is the system

## 4. Typography

### 4.1 Type families (locked)

#### Inter Tight — Display
*Variable sans-serif. Tighter than Inter, optimized for headlines and large display sizes. Used by Stripe, Notion, Mozilla.*
- License: Open Font License (OFL)
- Source: Google Fonts
- Self-host in production

#### Inter — Body & UI
*Variable sans-serif. The most-used premium UI typeface in 2026.*
- License: OFL
- Source: Google Fonts
- Self-host in production

#### JetBrains Mono — Data
*Variable monospace for numbers, codes, ANDA references, financial tickers.*
- License: Apache 2.0
- Source: Google Fonts
- Self-host in production

### 4.2 Why this pairing

Inter Tight + Inter is the contemporary "premium tech" pairing. Stripe uses it. Linear uses it. Vercel uses it. The combination signals:
- **Modern** — current standard for serious tech and biopharma
- **Restrained** — doesn't demand attention
- **Reliable** — never feels dated
- **Clean** — works at every size

It pairs naturally with Indigo because both signal "modern" without "futuristic" or "experimental."

### 4.4 Letter-spacing

| Size range | Letter-spacing |
|---|---|
| Display (44px+) | -0.04em |
| Headings (22–40px) | -0.03em |
| Sub-headings (16–22px) | -0.02em |
| Body (15–19px) | 0 |
| Eyebrows (uppercase) | 0.18em |

### 4.5 Italic emphasis

Italics in Inter Tight carry meaning. Used for:
- One or two emphasized words in a hero headline (e.g., "When a condition is *rare*")
- Pull quotes
- Scientific names (e.g., *fluocinolone acetonide*)
- The brand promise treatment ("*Care, codified.*")

When using italic emphasis, color it `--text-accent` (Saffron-700 on light, Saffron-300 on dark).

### 4.6 OpenType features

**Required when used:**
- Tabular figures (`tnum`) — REQUIRED for any data table, KPI strip, financial number, or stock ticker
- Stylistic alternates (`ss01`) — Inter's preferred alternate "g"
- Optical-size axis is NOT used (Inter Tight has no opsz axis); use weight instead

### 4.7 Heading order

Per WCAG 2.2 SC 1.3.1: never skip heading levels. H1 → H2 → H3 → H4. One H1 per page.

### 7.2 Duration

| Token | Value |
|---|---|
| `--duration-instant` | 100ms |
| `--duration-fast` | 200ms |
| `--duration-default` | 300ms |
| `--duration-slow` | 500ms |
| `--duration-deliberate` | 800ms |

### 7.3 Reduced motion (non-negotiable)

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    scroll-behavior: auto !important;
  }
}
```

WCAG 2.2 SC 2.3.3 — vestibular disorders affect 1 in 3 adults at some point.

### 7.4 Motion principles

1. **Purpose over flourish** — every animation clarifies a state change
2. **Direction has meaning** — entrances translate up (8–20px), exits mirror
3. **Stagger sparingly** — 50–80ms maximum
4. **Never block** — UI stays interactive during entrance animations
5. **Respect reduced motion** — non-essential motion suppressed

## 9. Photography & Imagery

### 9.1 Three approved modes

#### Mode 1 — Patient Documentary
*Real patients in their own environments.*
- Documentary framing, environmental portraits
- Natural light, soft shadows
- Slight desaturation, never over-treated
- Required: signed consent + photo release on file
- Required: caption with first name, age, condition, location
- Required: "Individual results may vary" disclaimer when adjacent to product mention
- **Reference:** Vertex Pharmaceuticals' patient story photography

#### Mode 2 — Manufacturing Editorial
*Inside Baudette, East Windsor, and Oakville facilities.*
- Real ANI employees, real production lines
- Macro details: vials, fill lines, quality lab equipment
- Cool color grade — slightly desaturated, industrial
- Branded PPE matches actual ANI specs
- Avoid generic "scientist holding flask" stock poses
- **Reference:** Patagonia factory documentary, NPR photojournalism

#### Mode 3 — Science Abstract
*Macro photography of vials, syringes, implants, formulations.*
- Beautiful. Lit deliberately. Studio.
- Generous negative space
- Brand-aligned color (no wild backgrounds)
- Used for: hero secondary imagery, product detail moments, editorial section breaks
- **Reference:** Apple product photography, Aesop product photography

### 9.2 Banned cliches

## 10. Voice & Tone

### 10.1 The six rules

1. **Direct.** Say what you mean. Cut adverbs. Plain English.
2. **Sourced.** Numbers cite their source. Claims cite evidence.
3. **Patient-centered.** "Patients" not "consumers." "People living with X" not "X sufferers."
4. **Confident, not arrogant.** Acknowledge what we haven't earned yet.
5. **Warm, not saccharine.** No emoji-laden positivity.
6. **Active over passive.** "We make medicines" not "Medicines are made."

### 10.2 Tone modulation by audience

The voice never changes. The tone modulates.

| Audience | Tone | Example |
|---|---|---|
| **Patient** | Warm, plain, supportive | "Your doctor and the support team can walk you through each step. You don't have to figure this out alone." |
| **HCP** | Clinical, peer-to-peer, evidence-led | "In the NEW DAY trial, ILUVIEN demonstrated [outcome]. See full PI for dosing considerations." |
| **Investor** | Precise, numerical, forward-looking | "2026 guidance reflects $1.055–$1.115B in net revenue with rare disease at ~60% of mix." |
| **Media** | Newsworthy, factual, quotable | "ANI is the only U.S.-based biopharmaceutical company commercializing a repository corticotropin therapy with a competitive WAC." |
| **Talent** | Mission-led, candid, energetic | "The work is rare. The impact is real." |

### 10.3 Headlines

- One idea, sometimes two, never three
- Editorial verbs ("transforming," "treating," "reaching") — not corporate verbs ("leveraging")
- Em dashes are fine. Semicolons are not.
- Italic emphasis (one or two words max) for the rhythm

✅ **Good:** "When a condition is rare, our commitment can't be."
❌ **Bad:** "Leveraging Innovation to Drive Transformative Patient Outcomes Across Therapeutic Areas"

### 10.4 CTAs

Verb + object. "Read our story." "Find your treatment." "See open roles."
- Never "Click here."
- Never "Learn more" alone — qualify what they'll learn.

### 10.5 Banned phrases

These phrases never appear in ANI copy. The system enforces.

`leverage` · `best-in-class` · `world-class` · `synergy` · `innovative solutions` · `cutting-edge` · `state-of-the-art` · `robust` (for portfolios) · `passionate about` · `thought leader` · `disruption` · `transformative` · `unprecedented` · `actionable insights` · `we're committed to`

### 10.6 Brand boilerplate

Use this verbatim in press releases, fact sheets, and bios:

> ANI Pharmaceuticals (NASDAQ: ANIP) is a diversified biopharmaceutical company developing, manufacturing, and commercializing therapeutics for people living with rare and uncommon conditions. Founded as a U.S.-based generics manufacturer, ANI today operates three FDA-inspected facilities and markets a rare disease franchise built around Cortrophin® Gel and ILUVIEN®. Our purpose is simple: serving patients, improving lives.

## 12. Pharma Compliance (FDA OPDP)

### 12.1 When these rules apply

Any page that names a branded product (Cortrophin® Gel, ILUVIEN®, YUTIQ®, or any prescription drug brand). NOT just product pages — ALSO press releases, earnings pages, insights articles, and patient stories that reference branded products.

### 12.2 Required elements when branded products are mentioned

1. **ISI Bar** — sticky bottom, expandable, full ISI text accessible
2. **Indications** for the branded product visible above the fold OR in the ISI
3. **Prescribing Information (PI)** linked as a downloadable PDF
4. **Adverse Event reporting** info: ANI Medical Info `1-800-308-6755` and FDA MedWatch `1-800-FDA-1088` / `fda.gov/medwatch`
5. **Job code** in footer (format: `US-CORP-2026-XXX` or `US-{BRAND}-XXXX`)
6. **Date of preparation** in footer (auto-stamped on publish)
7. **"This site is for U.S. audiences only."** disclaimer in footer

### 12.3 Fair balance (FDA enforcement Sept 2025)

Efficacy claims about a branded product MUST be accompanied by risk information **on the same page, in the same prominence**. "Click for safety info" links are insufficient. The September 2025 FDA crackdown issued 70+ untitled letters specifically for this violation.

### 12.4 HCP gating

Pages with HCP-only content (dosing, MOA detail, prescribing detail, rep contact) require an affirmation gate on entry.

```html
<div role="dialog" aria-modal="true" aria-labelledby="hcp-gate-title">
  <h2 id="hcp-gate-title">For Healthcare Professionals</h2>
  <p>I confirm I am a U.S.-licensed healthcare professional.</p>
  <button class="btn btn--primary">Yes, continue</button>
  <button class="btn btn--secondary">No, take me to patient resources</button>
</div>
```
- Soft gate (affirmation), not credential check — industry norm
- Persists for the session (don't re-prompt on every page)

### 12.5 Banned content

- ❌ Off-label indication discussion
- ❌ Comparative efficacy claims without head-to-head clinical data
- ❌ Patient testimonials about specific outcomes ("X cured my Y") — use experience-based stories with proper disclaimers
- ❌ Promotional content disguised as scientific/educational

### 12.6 MLR (Medical, Legal, Regulatory) review workflow

Every page that mentions a branded product passes through MLR before publish:

```
Draft → MLR Review → Approved → Published
```

The CMS enforces:
1. State machine on publish status
2. Required fields when branded products are mentioned (abbreviated indication, ISI link, PI link, AE reporting line)
3. Job code auto-generation per page
4. Date of preparation auto-stamped
5. Re-review trigger when product sections are edited

## 13. Accessibility (WCAG 2.2 AA — non-negotiable floor)

### 13.1 Required for every page

- [ ] `<html lang="en">` declared (SC 3.1.1)
- [ ] Skip-to-main-content link as first focusable element (SC 2.4.1)
- [ ] Heading order H1 → H2 → H3 (SC 1.3.1) · One H1 per page
- [ ] Focus visible on every interactive element with 3px Indigo ring (SC 2.4.7)
- [ ] Touch targets minimum 24×24 CSS px, 44×44 recommended (SC 2.5.8)
- [ ] All images have alt text (decorative: `aria-hidden="true"`)
- [ ] Color contrast ≥ 4.5:1 body, ≥ 3:1 large text (SC 1.4.3)
- [ ] Color is never the ONLY signal (SC 1.4.1)
- [ ] `prefers-reduced-motion` honored (SC 2.3.3)
- [ ] Page works with keyboard alone (SC 2.1.1)
- [ ] No keyboard traps (SC 2.1.2)

### 13.2 New in WCAG 2.2 (effective 2024+)

- **SC 2.4.11 Focus Not Obscured (Min)** — focused element not fully covered by sticky header/ISI bar
- **SC 2.5.7 Dragging Movements** — drag interactions have single-pointer alternative
- **SC 2.5.8 Target Size (Min)** — 24×24 CSS px minimum
- **SC 3.2.6 Consistent Help** — help mechanisms appear in consistent order
- **SC 3.3.7 Redundant Entry** — don't ask users to re-enter info already provided
- **SC 3.3.8 Accessible Authentication** — no cognitive function tests in auth

### 13.3 Required for forms

- [ ] Every input has associated `<label>` via `for`/`id`
- [ ] Required fields: visible `*` + `aria-required="true"` + `aria-label="required"` on `*`
- [ ] Error state: `aria-invalid="true"` + error described in text via `aria-describedby`
- [ ] Errors described in text, not just color (SC 1.4.1)

### 13.4 Required for sticky elements

- [ ] Focused elements never fully obscured by sticky bar (SC 2.4.11)
- [ ] Body padding accounts for sticky element height (e.g., `padding-bottom: 80px` for ISI bar)
- [ ] Sticky element collapsible with keyboard (Escape key)

### 13.5 Required for icon-only buttons

```html
<button class="btn-icon" aria-label="Open menu">
  <svg aria-hidden="true" focusable="false"><!-- icon --></svg>
</button>
```
